# Локальные данные ANPR Gate

В Git хранится только демонстрационный `vehicles_example.csv` и этот файл.

Приложение создаёт `anpr.sqlite3`, снимки в `snapshots/`, историю камер с учётными
данными в `recents.json` и журналы. Эти файлы относятся к конкретной установке.
Видео поместите в `videos/` либо выберите файл из любой папки в интерфейсе.
Датасеты оценки находятся локально в `eval/`.

Для резервной копии завершите приложение и сохраните базу, снимки и локальную
конфигурацию отдельно от репозитория. При переносе видео и датасетов учитывайте
содержащиеся в них номера и изображения людей.
